# Agent Seek Employment

本地优先的求职辅助工作台。项目以“简历版本 → 岗位机会 → JD 匹配 → 模拟面试 → 能力画像”为核心闭环。

## 技术栈

- Vue 3 + Vite + TypeScript
- Nuxt UI + Tailwind CSS
- Vue Router + Pinia
- pnpm

## 本地运行

```bash
pnpm dev
```

```bash
pnpm typecheck
pnpm build
```

## 当前阶段

已完成应用壳、路由与组件库接入。下一项业务任务是实现“简历主线 + 单线版本链”的 mock 闭环。
