# 开源 README 素材清单（暂存）

这个文件不是最终 README，而是为后续 GitHub 开源页积累真实、可验证的素材。对外 README 不应承诺尚未实现的能力。

## 应保留的项目叙事

- 产品名：**PERCH · AI Career Workspace**
- 一句话：将简历版本、岗位机会、结构化 JD 分析与面试准备串成可回看的求职工作流。
- 核心区别：不是泛聊天框，也不是一次性简历评分工具；每次分析都有对应简历版本、结构化结果和可观测运行记录。

## 对外应解释的工程决策

- 为什么 `Resume` 与 `ResumeVersion` 分开；为什么 JD 分析绑定具体版本。
- 为什么六个评分维度是跨行业固定 Rubric，具体能力只进入证据和风险项。
- 为什么用 Zod 校验模型输出，以及失败修复如何避免直接把脏 JSON 写入数据库。
- 为什么 AgentRun 要保存 Prompt 版本、模型名、原始输出、解析结果和重试信息。
- 为什么 RAG 暂不用于简历/JD 本身，而留给非结构化项目材料和面试笔记。
