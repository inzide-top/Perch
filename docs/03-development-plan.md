# Agent Seek Employment — 20 个工作日开发计划

## 使用方式

- 每天结束必须完成“验收”，不要只完成代码生成。
- **Vibe coding**：允许 AI 生成布局、组件样板、表单、样式、重复 CRUD、测试骨架。
- **亲自理解/实现**：数据模型、API 输入输出、Prompt 输入输出、工具权限、状态迁移、验收数据与错误处理。
- 每项 AI 生成代码先要求它说明：改哪些文件、数据如何流动、如何手测；再允许实现。

## 每周固定节奏

1. 周一：用真实数据定义本周验收样例。
2. 每天开发前：先写“输入、输出、异常、验收”四行说明，再让 AI 生成代码。
3. 每天开发后：手动操作一次主流程；记录一个 Bug 或一个设计疑问。
4. 周末：不加新功能，只跑真实简历与 JD，调整 Prompt 和 Schema。

## 何时开始 RAG / 向量化

不要为了简历和 JD 立刻加入向量数据库。只有当第二阶段加入 10 篇以上非结构化项目材料、面试复盘或 README，并且关键词查询难以找准证据时，再开始：

1. 文档切块；
2. 生成 embedding；
3. 存 pgvector；
4. 做“过滤后检索”；
5. 展示检索来源；
6. 对比“无 RAG / 有 RAG”回答质量。
