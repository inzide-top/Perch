# 配套虚构岗位与面试素材

以下单位、岗位和招聘需求均为产品演示创作，不代表真实招聘。使用同目录的“林知遥”简历；无需加入任何真实个人数据。

## 岗位 A：主要录屏场景

公司：栖岛数字产品工作室（虚构）

岗位：前端开发工程师（企业应用方向）

工作职责：

1. 使用 Vue 3、TypeScript 开发企业管理后台，负责列表、筛选和复杂动态表单。
2. 处理异步请求、失败重试与交互状态，保障复杂操作下的数据一致性。
3. 与后端协作落实权限相关的页面展示与接口约定。
4. 参与页面性能优化，使用可复现的数据说明优化前后差异。
5. 维护关键流程的自动化测试，参与持续集成。

任职要求：

- 2 年及以上前端开发经验，熟悉 Vue 3、TypeScript、Vue Router、Pinia。
- 有复杂表单和管理后台交付经验，能讲清状态划分与错误处理。
- 熟悉至少一种端到端测试工具，有关键业务链路自动化测试经验。
- 理解前后端权限边界，能说明仅隐藏按钮为什么不能保障接口安全。
- 有键盘可访问性或性能测量经验者优先。

预期可讨论的证据：Vue、表单、请求竞态有项目支持；端到端测试和 CI 经验缺乏明确证据；“知道权限边界”仍应通过面试验证。以上是人工设计的对照点，不能冒充实际 AI 输出，也不预设分数。

## 岗位 B：跨岗位比较备用

公司：纸舟协作工具社（虚构）

岗位：前端开发工程师（协作产品方向）

职责：维护 Vue 3 协作后台，开发复杂表单与数据筛选；改善键盘操作体验；补充关键链路端到端测试并接入 CI。

要求：熟悉 TypeScript 与组件设计，有异步状态处理经验；能建立可维护的自动化测试；有 WebSocket 或多人协作功能经验者优先。

对照点：与岗位 A 都要求自动化测试，可用于验证策略聚合；WebSocket 与多人协作无现有简历证据，不能自动写成候选人技能。

## 岗位 C：明显不匹配备用

公司：远帆系统研究室（虚构）

岗位：高级前端平台工程师

要求：5 年以上经验，主导 React 和服务端渲染架构，设计 Node.js 服务与监控，负责大型前端平台 CI/CD、端到端测试体系和团队技术决策。

对照点：年限、React、SSR、服务端架构与团队技术决策均缺少支持证据。用于观察系统能否识别缺口，不能用来证明系统一定准确。

## 模拟面试回答素材

只有系统实际提问相近内容时才使用；不要把预写问题伪装成应用自动生成的问题。

问题方向：快速切换筛选条件，如何避免列表显示旧结果？

第一轮示例回答（故意不完整）：

> 我会给搜索输入加防抖，等用户停止输入以后再发请求，这样请求数量会少一些。

追问后的补充回答：

> 防抖只能减少触发次数，不能保证响应顺序。我会在新查询开始时取消旧请求，同时为每次查询分配递增序号。响应回来时，只有序号仍等于当前查询序号才更新列表、错误和加载状态。组件卸载时也取消请求。测试时模拟先发请求后返回，确认旧响应不会覆盖新结果；取消产生的异常不弹成普通业务错误。

可观察点：反馈是否区分“减少请求”和“避免竞态”，是否给出与回答相符的建议。模型不一定提到所有点，展示真实结果即可。
