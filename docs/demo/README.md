# 虚构演示数据

所有人物、院校、公司、项目与指标均为虚构设定，用于体验 Perch 的导入、分析和面试准备流程，不可用于真实求职。

- [演示简历 PDF](./demo-resume.pdf)：2 页文本 PDF，可用于“简历管理”的 PDF 导入。已使用本项目 unpdf 验证能提取中文文本；AI 结构化结果仍需在确认页核对。
- [简历 Markdown](./resume.md)：方便阅读和手工填表。
- [简历纯文本](./demo-resume.txt)：备用文本素材，不代表应用支持 TXT 文件上传。
- [岗位与面试素材](./jobs-and-interview.md)：岗位 A 用于主流程；B 用于比较需求；C 用于观察明显差距。
- [创建简历请求样例](./demo-resume-create.json)：符合服务端 `createResumeInputSchema` 的开发夹具，不代表界面提供 JSON 导入。需要在隔离的开发环境中由开发者按实际认证方式调用，勿将样例自动写入生产账号。

建议流程：先配置模型 → 导入 PDF 并确认 → 创建岗位 A 并关联简历 → 发起 JD 分析 → 查看实际证据与缺口 → 完成一道模拟面试。

候选人有 Vue、复杂表单与单元测试经历，缺少端到端自动化测试体系证据，因此便于展示匹配与追问。这里只提供人工设计的观察点，不预设 AI 分数或输出。不要把模拟项目指标当成产品效果证明。
